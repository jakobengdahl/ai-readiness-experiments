# LLM Wiki

This directory is the shareable/public-facing LLM Wiki area for AI-ready dissemination work.

Rules:
- only sanitized material belongs here
- no secrets, tokens, personal access keys, or private credentials
- no project-specific personal names unless explicitly approved for publication
- raw sources copied here must already be reviewed for shareability

Core files:
- `SCHEMA.md` — rules for how the wiki is structured
- `index.md` — catalog of current pages
- `log.md` — append-only operational log
- `_meta/SANITIZATION_POLICY.md` — what must stay out
- `_meta/RELEASE_CHECKLIST.md` — pre-push/public-share checklist
- `tools/sanitize_check.py` — local scanner for obvious leaks

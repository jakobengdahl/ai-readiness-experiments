# AI Readiness Experiments

This repository contains experiments, prototypes, and practical notes related to AI-ready statistical dissemination. It is intended as a working space for testing how official statistics and related data flows can be exposed, structured, and consumed effectively through modern AI assistants and agent-based interfaces.

## LLM Wiki workspace

A shareable LLM Wiki scaffold lives in `llm-wiki/`.

Design goals:
- keep the wiki content shareable by default
- keep sensitive ingestion/staging material out of the repository
- support future ingestion from Telegram uploads and/or a Google Drive folder
- allow the public wiki area to be mirrored back to GitHub cleanly

Read `docs/llm-wiki-workflow.md` for the architecture, sanitization workflow, Obsidian notes, and hosting guidance.
